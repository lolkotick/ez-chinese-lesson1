# EZ Chinese: 第一课 建立联系 (Спринт за 2 часа)

> 🌐 **Онлайн-версия (работает в любом браузере с любого устройства)**:  
> **[https://lolkotick.github.io/ez-chinese-lesson1/](https://lolkotick.github.io/ez-chinese-lesson1/)**

Интерактивное приложение для быстрого запоминания 50 новых слов и 7 имен собственных из первого урока бизнес-китайского языка («建立联系 — Установление контактов»).

---

## 🚀 Быстрый запуск

### Запуск в режиме разработки:
```bash
npm run dev
```
Откройте в браузере адрес, указанный в терминале (обычно `http://localhost:5173`).

### Сборка готового приложения:
```bash
npm run build
npm run preview
```

## 🧠 Методика ускоренного запоминания за 2 часа

Слова разбиты на **6 тематических блоков** по 9–10 слов:
1. **Блок 1 (№1–10)**: Основы и деловые контакты (*纺织品, 总公司, 顺风, 关照, 希望, 期间, 允许, 委派, 具体, 代表团*)
2. **Блок 2 (№11–20)**: Персонал и связи (*成员, 助手, 保持, 密切, 询问, 结识, 商务, 推荐, 附上, 需要*)
3. **Блок 3 (№21–30)**: Заказы и структуры (*订购, 目录, 委员会, 投石问路, 简便, 驻, 机构, 官方, 处, 民间*)
4. **Блок 4 (№31–40)**: Филиалы и география (*子公司, 专业, 资料, 范围, 渠道, 举办, 博览会, 省, 市, 地方*)
5. **Блок 5 (№41–50)**: Ярмарки и инвестиции (*交易会, 综合性, 大型, 积极, 参展, 纷纷, 区域, 招商, 牵线搭桥, 道路*)
6. **Блок 6 (№51–57)**: Имена и ведомства (*纽约, 罗斯, 杰克逊, 布朗, 商务部, 天津, 广交会*)

### 4 шага на каждый блок:
- 🗂️ **Карточки (Flashcards)** — 10 минут на блок. Изучите визуальный образ и морфемный состав слова (почему иероглифы значат именно это).
- ⚡ **Спид-пары (Speed Match)** — 5 минут на блок. Скоростное соединение иероглифов с русским переводом. Развивает моментальное узнавание.
- 🎯 **Тест (Quiz)** — Проверка со случайными дистракторами и аудированием.
- 🎵 **Тоны (Tone Drill)** — Тренировка тонов и правильного интонирования.
- 🏆 **Финальный зачёт (Exam)** — Итоговый тест на 100% с выдачей списка слабых мест для доработки.

## 💡 Особенности

- 🔊 **Нативная китайская озвучка**: Web Speech API (`zh-CN`) с регулировкой скорости (0.75x, 0.85x, 1.0x).
- 🎨 **Цветовая подсветка тонов**: 1 тон (красный), 2 тон (зеленый), 3 тон (синий), 4 тон (фиолетовый).
- 👁️ **Режим «Скрыть пиньинь»**: для тренировки распознавания «вслепую» только по иероглифам.
- 🧩 **Морфемный разбор**: для каждого многосложного слова приведен детальный перевод составляющих его иероглифов.
- 💾 **Автосохранение**: Весь прогресс, статистика и изученные слова сохраняются в `localStorage` браузера.
- ⌨️ **Горячие клавиши**:
  - `Space`: перевернуть карточку / озвучить
  - `1`, `2`, `3`, `4`: варианты ответов в тестах и оценка карточек
  - `←` / `→`: листать карточки
